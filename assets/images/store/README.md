# Store photography slots

Place original photographs of the physical DE LA BOSS OUTFITS shop here.
The gallery on `index.html` and `about.html` picks them up automatically —
no HTML edit needed.

## File names and slots

| File | Slot | Intended subject |
| --- | --- | --- |
| `store-01.jpg` | 01 | Shop front / entrance, signage visible |
| `store-02.jpg` | 02 | The clothing rail or display wall |
| `store-03.jpg` | 03 | Styling or fitting corner |
| `store-04.jpg` | 04 | Accessories, footwear or detail shot |
| `store-05.jpg` | 05 | The team at work (with consent) |

`about.html` uses slots 01–03.

## Requirements

- **Portrait orientation, 3:4** (for example 900 × 1200 px or 1200 × 1600 px).
- **JPG or WebP**, roughly 150–250 KB each after compression.
- Natural light where possible; avoid heavy filters and text overlays.
- Only photographs the business owns or has permission to publish.
  Never use a customer's photo without their consent.
- Update the `alt` text in the HTML if the subject of a slot changes.

## Rights and honesty

These slots exist so real shop photography can replace stock imagery.
Until they are filled, each tile shows a labelled placeholder reading
"Awaiting photograph" — no stock image is ever presented as the shop.
